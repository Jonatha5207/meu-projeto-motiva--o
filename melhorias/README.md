# Melhorias do Companheiro

Esta pasta organiza a evolucao do app sem misturar planejamento com o codigo principal.

## Prioridades

- `produto.md`: jornada para ajudar a pessoa a manter o habito.
- `social.md`: feed, grupos, seguidores, comentarios e eventos em tempo real.
- `experiencia.md`: melhorias de layout, acessibilidade e experiencia mobile.
- `tecnico.md`: banco de dados, seguranca, notificacoes e escalabilidade.
- `testes.md`: roteiro para validar cada funcao antes de publicar.

## Ordem recomendada

1. Fazer todas as funcoes principais funcionarem no celular.
2. Persistir usuarios, posts e interacoes no backend.
3. Adicionar notificacoes e acompanhamento de progresso.
4. Testar com usuarios reais antes de lancar.
